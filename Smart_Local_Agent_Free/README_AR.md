# الوكيل الهندسي المحلي الذكي — `Smart_Local_Agent_Free` (الإصدار `v10.13.2`)

نظام محلي مجاني 100% باللغة العربية (`RTL`) لإدارة مستندات وأرشفة المشاريع الهندسية والمقاولات (مع دعم الدينار الكويتي بـ 3 خانات عشرية `0.000 د.ك`)، مصمَّم خصيصاً للعمل اليومي المريح على جهاز واحد أو عدة أجهزة (مثلاً: مشروع على الجهاز الأول ومشروعان على الجهاز الثاني) مع **حماية صفر-حذف في الأرشفة والتنظيم التلقائي** (وتأكيد صريح للحذف اليدوي).

---

## أهم مميزات الإصدار `v10.13.2`

1. **📗 سجل Excel مرفوع خاص بكل مشروع (تعديل مباشر وليس لوجاً عاماً):**
   - داخل كل مشروع تبويب مخصّص **«سجل المشروع المرفوع»** (`3_Project_Logs/`) لرفع ملف اللوج الفعلي الخاص بالمشروع (`.xlsx` أو `.xlsm`).
   - يقرأ النظام شيتات اللوج وأعمدته ويعدّل عليه مباشرةً عند الأرشفة أو إصدار المستندات أو ورود الردود والمراجعات (`REV.0 .. REV.N`)، مع الحفاظ الكامل على الماكرو (`VBA`) والمعادلات والتنسيقات.
   - واجهة بصرية لربط وتأكيد الشيتات والأعمدة، وقائمة انتظار آمنة تحفظ القيود تلقائياً إذا كان ملف اللوج مفتوحاً في Excel وتفرّغها فور إغلاقه.

2. **🎨 استوديو النماذج المرفوعة فقط (لا توجد أي نماذج مقترحة من النظام):**
   - يعرض النظام فقط النماذج التي ترفعها أنت لكل مشروع في `4_Project_Templates/` (`.xlsx`، `.xlsm`، `.docx`).
   - **معاينة بصرية مطابقة بالعرض المقسوم (Split View):** شيتات Excel بالخلايا المدمجة والألوان والحدود والشعارات والتحديد الفردي أو بالسحب المستطيل، ومستندات Word بورقة `A4` تفاعلية (أو صور صفحات مطابقة عند توفر LibreOffice).
   - **6 أدوار دقيقة للحقول:** ثابت (`fixed`)، إدخال يدوي (`manual`: نص، فقرة، تاريخ، رقم، مبلغ `0.000 د.ك`، قائمة منسدلة، كود اعتماد `A/B/C/D`، إلزامي، قيمة افتراضية)، تلقائي من المشروع (`auto_project`)، تلقائي من النظام (`auto_system`)، معادلة محمية (`formula_protected`)، وجدول بنود متكرر (`repeating_table`) يوسّع معادلات `SUM` تلقائياً.
   - **كشف تعديل القالب ببصمة `SHA-256`:** إعادة ربط تلقائية للحقول المزاحة، وإيقاف فوري مع تحذير عند وجود حقل يتيم لحماية المستند.
   - **معاينة حية + إصدار رسمي + شاشات أقسام مستقلة:** حفظ المستند في `2_Archive/.../00_Editable_Originals/` وتسجيله تلقائياً في لوج المشروع المرفوع بحالة `Under Review`.

3. **🧹 منظّم المشاريع، أرشيف الواتساب، وكاشف المكررات والتشابه بالمحتوى (`v10.6–v10.13.2`):**
   - **منظّم المشاريع:** فرز وتسمية آلاف الملفات على القرص أو خوادم الشبكة مع عزل المكرر والأقدم وتدقيق السجل، بالإضافة لأدوات تقسيم ودمج PDF ومؤشرات التقدم الحية وزر الإيقاف.
   - **أرشيف الواتساب:** مطابقة تلقائية لصور ومستندات تصدير واتساب مع التواريخ والتعليقات قبلها/بعدها والألبومات المتصلة مع فلترة زمنية وتسمية بالذكاء الاصطناعي.
   - **المكررات والتشابه بالمحتوى:** كشف التطابق التام (`SHA-256`) والتشابه البصري للصور وتشابه نصوص المستندات مع عزل قابل للتراجع (`Quarantine`) أو تصدير ZIP فريد.

4. **⚖️ حماية الأرشيف واللوج من الملفات غير المرتبطة بالمشروع:**
   - فحص ذكي لارتباط كل ملف بالمشروع النشط مع ثلاث سياسات قابلة للتخصيص:
     - **تسمية نظيفة في مكانه (`rename_in_place` — الافتراضي):** دون نقله للأرشيف أو إدخاله في لوج المشروع، مع زر **تراجع (Undo)** فوري ومنع إعادة الفحص ببصمة `SHA-256`.
     - **توجيه لمجلد باسم الجهة (`new_project_by_name`):** مع مطابقة عربية ذكية تمنع تكرار المجلدات لنفس الجهة.
     - **السؤال في القرارات المعلقة (`ask`):** مع إمكانية حفظ قرارك في **القواعد المتعلَّمة** (`learned_rules.json`) وتعديلها متى شئت.
   - دعم وضع التجربة (`Dry-Run`)، أنماط التجاهل، وفحص الملفات المفتوحة/المقفولة.

5. **▶ المشروع النشط + بدء العمل/مزامنة + إنهاء الجلسة (مثالي لتعدد المشاريع والأجهزة):**
   - شريط علوي دائم يوضح **المشروع النشط** ويمنع اختلاط مستندات مشروعين على نفس الجهاز (`active_only` افتراضياً).
   - **«بدء العمل / مزامنة»:** يفرّغ القيود المعلقة ويعيد حساب جميع الأرقام التسلسلية مباشرةً من لوج المشروع المرفوع (`max + 1`).
   - **«إنهاء الجلسة»:** يتأكد من إغلاق جميع الملفات وينشئ نسخة احتياطية مؤرخة في `_Backups/` (ونسخة خارجية اختيارية للفلاشة/القرص الخارجي) مع تنبيه إذا مرّ أكثر من 7 أيام دون نسخ احتياطي.

6. **🔒 أمان محلي والفرق بين العمل الأوفلاين والاتصال بـ Gemini:**
   - يعمل الخادم محلياً على `127.0.0.1` فقط مع فحص `Host`/`Origin` لجميع طلبات `GET` و`POST` و`DELETE` لمنع هجمات DNS Rebinding وCSRF، وواجهة عربية بدون أي روابط `CDN` خارجية.
   - **حماية صفر-حذف في الأرشفة والتنظيم التلقائي:** لا يحذف المحرك التلقائي أو السكانر أي ملف، بل ينقله لمجلدات الأرشفة أو العزل؛ أما الحذف اليدوي النهائي (مثل خيار «حذف مع الملفات» الذي يزيل مجلد المشروع مع `_Backups` بداخله، أو «الحذف النهائي للمكررات») فيتطلب تأكيداً صريحاً بالاسم/التأكيد المزدوج.
   - **متى يكون العمل أوفلاين 100%؟** يكون أوفلاين بالكامل عند التشغيل بدون ذكاء اصطناعي أو باستخدام **Ollama المحلي** فقط؛ أما عند تفعيل **Gemini (مفتاح API أو CLI)** فتُرسل نصوص/صور المستندات إلى Google API وفق سياسة الخصوصية لخطة حسابك (يُرجى مراجعة شروط Google لخطتك للمستندات السرية وشروط تعدد المفاتيح). ومفاتيح Gemini تُحفظ محلياً في `~/.gemini` فقط ولا تُكتب أبداً في أي ملف مشروع.
   - **ملاحظة التراخيص:** يعتمد تقسيم ودمج وتصوير صفحات PDF اختيارياً على مكتبة `PyMuPDF` المرخَّصة بـ `AGPL-3.0` (راجع شروط الرخصة عند التوزيع الخارجي خارج نطاق الاستخدام الداخلي).

## طريقة التثبيت والتشغيل السريع (Windows)

- **تثبيت لأول مرة:** شغّل `1_INSTALL_FIRST_TIME.bat` (أو `00_DOWNLOAD_REQUIREMENTS.bat` لتحميل المتطلبات).
- **تحديث من إصدار سابق في ثانية واحدة (دون مساس بمشاريعك أو سجلاتك):** شغّل `UPDATE_QUICK.bat`.
- **فتح التطبيق البصري اليومي:** شغّل `0_OPEN_PROJECTS_APP.bat` (أو اختصار سطح المكتب **`Smart Projects Hub`**) ليفتح على `http://127.0.0.1:8765`.

### خطوات العمل اليومي الموصى بها:
1. أنشئ المشروع وارفع **ملف لوج Excel الخاص به** من تبويب «سجل المشروع المرفوع» وراجع ربط شيتاته.
2. ارفع **نماذجك المعتمدة** (`.xlsx` / `.xlsm` / `.docx`) في «استوديو النماذج المرفوعة»، أكّد القسم وحدّد الحقول ثم احفظ البروفايل.
3. في بداية اليوم اضغط **«▶ بدء العمل / مزامنة»**، وفي نهاية اليوم اضغط **«⏹ إنهاء الجلسة»** لحفظ النسخة الاحتياطية المؤرخة بأمان.

## هيكل مجلد كل مشروع

```text
<كود المشروع - اسم المشروع>/
├── 1_Inbox/                 # صندوق الوارد وملفات السكانر (+ سجل التراجع _rename_journal.json)
├── 2_Archive/               # الأرشيف الهندسي المنظّم حسب الأقسام (+ 00_Editable_Originals)
├── 3_Project_Logs/          # سجل (أو سجلات) Excel المرفوعة الخاصة بهذا المشروع + .logmap.json
├── 4_Project_Templates/     # نماذجك المرفوعة فقط (.xlsx/.xlsm/.docx) + .tplmap.json
├── _Backups/                # النسخ الاحتياطية المؤرخة التلقائية عند إنهاء الجلسة
└── _System_Agent/           # ملفات الحالة المحلية وقائمة الانتظار الآمنة
```
